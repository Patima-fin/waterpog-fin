ตั้งค่า Supabase Auth — สร้างผู้ใช้ + รหัสใหม่

สร้างบัญชี Supabase Auth ให้ทีม (จาก USERS ใน config.js) พร้อมรหัสผ่านใหม่ + ฝัง role ใน app_metadata (ใช้กับ RLS)

🔐 service_role key คือกุญแจระดับสูงสุด — วางในหน้านี้ใช้ครั้งเดียวในเครื่องคุณเท่านั้น (เก็บในหน่วยความจำ ไม่บันทึก ไม่ขึ้น repo). เอาจาก Supabase → Project Settings → API → service_role · secret (กด Reveal).
★ ทำเสร็จแนะนำ หมุน (regenerate) service_role key ใน Supabase เพื่อความปลอดภัยสูงสุด (แอปใช้แค่ anon key ไม่กระทบ)
